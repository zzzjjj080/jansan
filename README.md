# 雀算（Jansan）

麻雀のスコアを「打つだけ」で記録する iOS アプリです。
余計な項目を削って、入力の速さだけを突き詰めています。

## 特徴

- **3人分を入れれば4人目は自動** — その局の合計が0になるよう逆算します。あとから他の人を訂正すれば連動して計算し直されます
- **2桁でそのまま次の人へ** — 「確定」を押す手間がありません。3桁を打ちたいときは続けて打てば入ります
- **5〜6人で回しても崩れない** — 3人分を入れたあと実際に打った4人目をタップすると確定し、残りはその局だけ自動で「お休み」になります
- **人数と局数に応じて自動縮小** — 横スクロールなし。縮みきったらスクロールに切り替え、名前の行と合計の行は常に見えたままです
- **閉じても消えない** — 入力中の内容は自動保存。残したい対局は日付付きで記録できます
- **記録はiCloudに残る** — お使いのiCloud（プライベートデータベース）に同期するので、端末が壊れても機種を変えても記録は消えません。開発者からも他の利用者からも見えません
- **卓ごとに分けて、仲間と共有できる** — 記録は「ディレクトリ」に分けて残せます。IDとパスワードを決めて共有をオンにすると、その2つを知っている人が同じ記録を見られます（見るだけで、書き換えはできません）
- **広告も解析も入っていない** — 点数が開発者や第三者へ送られることはありません。外部と通信するのは、iCloudへの同期、**共有をオンにしたディレクトリの送受信**、任意の「開発者にコーヒーを奢る」（App内課金）のときだけです。共有をオンにしない限り、点数が他の人に見えることはありません

## CSV の取り込み（1.4〜）

記録の画面でディレクトリを開き、右上のメニューの「CSVを貼って取り込む」から入れる。
**書き出し（CSV）をそのまま貼れば戻る**ことを第一にしている（`JansanCore/Sources/JansanCore/CSVImport.swift`）。

```
No,中村,五十嵐,斎藤,佐々木,田中
1,30,10,-10,-30,
2,-20,40,,-20,0
合計,10,50,-10,-50,0
```

- 1行目は名前（3〜6人）。1列目が `No`・`局`・`#`・空欄なら、各行の1列目は局の番号
- 空欄はその局のお休み。小数点が1つでもあれば小数点モードの表として読む
- 三麻/四麻は「参加3人、またはどの局も3人ぶん」なら三麻、それ以外は四麻
- `合計` の行は読み飛ばすが、計算した合計と違えば知らせる
- 名前の行が続けて2回来たら、前の行は題名とみなして捨てる。表を続けて貼ると表ごとに1件
- タブ区切り（表計算ソフトからのコピー）・全角の数字・`＋` `－` `▲` も読む
- 同じ中身の表は二度入らない（書き出したCSVの文字列で比べる）
- **日付は「日付未記入」で入る。** `playedAt` に 1970-01-01 を入れて見分ける（引き継ぎ書 4-127）。記録の編集で入れる
- 写真や他のアプリの画面は、画面にある「お願い文」を付けて AI に変換してもらう。お願い文の例が取り込めることはテストで固定している

## 集計（1.4〜）

ディレクトリの右上の集計ボタンから開く。数えるのは `JansanCore/Sources/JansanCore/PlayerReport.swift`。

- **打ち方（三麻/四麻）で分ける。人数では分けない。** 5人で回す四麻は四麻。混ぜた「すべて」は置かない（着順の分母が変わる）
- 打ち方は `min(playersPerRound, 参加人数)`。三麻/四麻を選べる前の3人の表は、保存に項目が無く既定の4で読まれるため
- **着順は局ごとに付ける。** 同点は表の左の人が上（表の中の集計と同じ）。全員の点が入った局だけ数える
- **ラスはその局の最下位。** 自分の最低着順で数えると、一度も4位が無い人の3位がラスになる（1.3 までの表はこれだった）
- 期間は 全期間・最近20局・今年 の3つ。**最近20局は日付ではなく局で区切る**（`Report.latest`。新しい方から数え、境目の対局は新しい局だけ残す）
- 画面：ハイライト 3×3（トップ率・平均着順・連続トップ／ラス回避率・最高の日・絶好調／最多参加・最高の1局・痛恨の1局）→ 成績表（局・合計・平均・平着・トップ・連対・ラス）→ 着順の割合 → 累計の推移
- ハイライトの枠は、その人の色（表・グラフと同じ）で塗る。**デザインは「コーナー金具」を元にした四角の枠**：暗い地に、その人の色で光る切れ目のない四角の枠、項目ならではの絵（`Illustration`：王冠・星・炎・トロフィー・盾・メダル・稲妻・カレンダー・雷雨）を大きく透かす。試作を2回（計18種）見比べて本人が選んだ
- 最高の1局・最高の対局・痛恨の1局・連続トップには、その記録を出した日を添える（同じ点・同じ長さなら先に出した日）
- 成績表の率（トップ率・連対率・ラス率）は％を付けず、見出しに「率」と書く。名前の欄は一番長い名前に合わせる。余った幅は表の左右に半分ずつ（名前の欄を先に広げる `layoutPriority`）
- **連続記録は1回の記録（その日の表）の中だけで数える。** 次の記録に移ると途切れる。最長を出した記録の対局日を持ち、画面に出す（同じ長さなら先に出した日）
- 表の上の「個人成績の詳細を見る」から、1人ずつ横に送る画面（`PlayerPagerView`）を開く。**入口はこのボタンだけ**（表の行からは開かない。本人の指示）。ボタンは緑の線だけの枠に文字と矢印（10種類の試作から本人が選んだ「線だけ」）。並びは表と同じ合計の多い順。上の帯に何人目か・人の色の点・前後の矢印
- 1人ぶんの詳細：着順の分布と率、1局の点数（プラス率・最高・最低）、連続記録と日付、対局ごとの成績、直近10局の調子、相手ごとの相性（同じ局を打った数・着順で上回った割合・1局あたりの点差）
- 率を並べるハイライト（ラス回避率・平均着順・絶好調）は5局以上打った人だけを対象にする
- トップ率は回数ではなく率（「◯回中 ◯回」を添える。5局以上の人が対象）。最高の日は1回の記録（その日）の合計が一番多い人。最高の1局は痛恨の1局の隣（下段の真ん中）に置き、1局の最高と最低を並べる。ただし率のハイライトが対象者なしで出ないと、前に詰まって位置がずれる
- 平均着順には「参加◯回の平均」、最多参加は「◯回」と「全◯局中の参加回数」を添える（「皆勤賞」にしない。全部に出ていなくても1番なら出るため）
- **最近の記録**：集計の一番下に、対局日がいちばん新しい記録を入力の表と同じ情報（局ごとの点数と合計）で出す（同じ日付なら後から保存した方）。表は保存した記録の画面と共通の `RoundTableView`（画像にするときは横に送らず幅に収める `fitsWidth`）
- **画像で送る**：画面と同じ部品をそのまま4枚の画像にする。並びは ①最近の記録（共有で一番知りたいもの）②累計の表 ③ハイライト ④着順の割合と推移（`ShareImagesSheet`。画面の幅402ptを3倍で、いまのライト／ダークのまま）。題名などの共通の見出しは載せない。ハイライトは `LazyVGrid` だと `ImageRenderer` で空になることがあるので普通の `Grid`
- ラス回避率には分母と分子を添える（「15局中 ラス0回」）。詳細の行も同じ
- 記録タブのディレクトリ一覧：各行は上に「名前（件数）」と丸い印（保存先・共有中）、下に大きな「詳細」（中の記録の一覧）と「集計」の2つのボタン。**中に入るのは「詳細」ボタンからだけ**（行のほかの場所は押しても何も起きない）。右端の「＞」は付けない（`NavigationStack(path:)` に自分で積む）。IDとパスワードは一覧に出さず、詳細を開いた一番上に出す（`HistoryView.shareInfo`）。自動バックアップには集計ボタンを出さない
- 自動バックアップ：一覧では**共有されたものより下**の別枠に置く。控えは**記録されてから暦の1か月たったら消す**（`AutoBackupRetention`、起動時・前面に戻ったとき・一覧を開いたとき・控えを取ったときに `DirectoryStore.pruneAutoBackups`）。30件を超えたら1か月以内でも古いものから捨てる。全部消えて0件になっても行は残し、**灰色にして押せなくする**（スワイプ削除も出さない）。テストでは Debug ビルドの起動引数 `-autoBackupClockOffsetDays 40` で「いま」をずらす
- 保存の確認：「残す」を押したとき、保存先に**人も点数もまったく同じ記録**（書き出しのCSVが一致）があれば、「同じ記録がすでにあります」ともう1回確かめる（日付つき）。「それでも残す」で保存、「やめる」で何もしない
- 共有の人数：受け取った端末が公開DBに**受け取り票**（`ShareReceipt`、端末ごとの乱数と最後に見た日時）を1枚置く。置き場所は共有レコード名＋番号の決まった64枠で、送った側は64件をまとめて取って数える（検索の索引が要らない）。詳細の一番上に「3人が受け取り中・最後に見たのは 9/14」。受け取るのをやめると票を消す。iCloud にサインインしていない端末は数に入らない
- バックアップ：書き出しに**フォルダの一覧（名前・識別子・並び順）と、記録ごとのフォルダ**を入れる（`BackupDirectory`）。戻すとき、無いフォルダは作り直して記録を元のフォルダへ入れる。**共有のIDとパスワードは書き出しに入れない**（ファイルが人に渡ると共有を書き換えられるため）。フォルダの情報が無い古いバックアップは、これまでどおりマイ記録へ。貼り付け欄に「ペースト」ボタン
- 写真から取り込む（1.6）：記録タブの ＋ の隣から開く。**アプリ自身は写真を読まない**。画面はやり方（5手順）→「AIへのお願い文をコピー」→ 返ってきた表を貼る → 中身を確かめる → 取り込む、の一本道。押す所は大きく（`bigLabel`）。**端末内の文字認識（Vision）も、APIキーでAIに送る仕組みも、1.6 の開発中に作って外した**（前者は手書きが崩れて実用にならず、後者は使う場面が無いと判断。履歴は 272dbaa 付近）
- 読み取りの崩れ：「合計」が「合卵9」のように化けた行は、**点数の行のあと・残りが全部数字**のときだけ合計とみなして飛ばす（`CSVImport.isGarbledTotalRow`）
- CloudKit の接続先：開発用ビルドも **本番（Production）** に繋ぐ（`Jansan.entitlements` の `icloud-container-environment`）。開発環境で共有したものは App Store 版から見つからなかったため（引き継ぎ書 4-146）。切り替え後の初回起動で、共有中のフォルダを1回だけ本番へ送り直す
- 設定のいちばん下に入っている版（`1.5 (7) · b120 09/14 01:30`）。印は `install-device.sh` が `JS_BUILD_STAMP` で入れる
- **絶好調は卓全体の直近20局（`Report.hotWindow`）での1局平均点。** その20局を5局以上打った人が対象。その人が打った直近で数えると、しばらく来ていない人の昔の好成績が残り続けるため（`Report.recentWindow`）
- 皆勤賞は局数、痛恨の1局は1局の最低点（負けた人の名前が出る。本人が選んで入れた）
- **人の色は、ディレクトリの全記録（全期間・三麻と四麻の両方）で初めて出てきた順に割り当てる。** 期間や打ち方を切り替えても同じ人は同じ色
- 着順の割合は1局平均点の高い順に並べ、1割以上の区間に割合を書く。着順の色は 1位 緑・2位 青みの灰・3位 黄土・最下位 赤
- 詳細の「最近の調子」は、その人が打った直近10局（`Report.recentRounds`）
- 期間で絞ったとき、日付未記入の対局は落ちる。件数が合わなくならないよう、画面に「日付未記入の N 対局は全期間でだけ数えます」と出す

記録の一覧（ディレクトリの中）は**対局日の新しい順**。対局日の無い古い記録は保存日時で並べ、日付未記入は最後（`PlayedDate.newestFirst`）。

## フォルダの削除（1.5〜）

- **記録が2件以上ある自分のフォルダは、既定では削除できない**（`Directory.protectedRecordCount`）。一覧のスワイプ削除も、フォルダの中の「ディレクトリを削除」も、確認に進む前に「このフォルダは削除できません」と理由を出して断る
- 設定の「データ」にある「記録が2件以上あるフォルダも削除できる」（`allowDeletingDirectoriesWithRecords`、既定はオフ）をオンにしたときだけ消せる
- 受け取ったフォルダの「受け取るのをやめる」は対象外（手元の写しを消すだけで、また受け取れる）。マイ記録はもともと消せない

## 構成

```
JansanCore/   点数計算のロジック（UI非依存・テスト39本）
Jansan/       iOSアプリ（SwiftUI）
docs/         サポートページとプライバシーポリシー（GitHub Pages）
store/        App Store提出用のスクリーンショットと掲載文
```

計算の中身はすべて `JansanCore` に閉じています。UIから切り離してあるので、
逆算・自動移動・お休み判定・着順集計といった一番壊れやすい部分をテストで固定できます。

```bash
cd JansanCore && swift test
```

マスの状態は enum で表現していて、「手入力なのにお休み」のような
あり得ない組み合わせをそもそも作れないようにしています。

```swift
enum Entry {
    case empty          // 入力待ち
    case resting        // その局は不参加
    case entered(Int)   // 手入力
    case derived(Int)   // 合計0から逆算
}
```

## ビルド

Xcode 26 以降が必要です。対応は iOS 18.0 以降の iPhone。

```bash
open Jansan/Jansan.xcodeproj
```

`JansanCore` はローカルの Swift Package として参照しているため、追加の取得作業はありません。

## 開発用の道具

- `Tools-MakeIcon.swift` — アプリアイコンを生成します
- `store/MakeScreenshots.swift` — スクリーンショットに見出しを載せて App Store 用に組みます

どちらも `swiftc` で直接コンパイルして実行できます。
